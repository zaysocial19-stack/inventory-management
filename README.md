## AI Session Rule

Before working on the project, the coding assistant should read `PROJECT.md`, `ROADMAP.md`, and `docs/SESSION.md`, plus any relevant documentation.

This is a learning project. The assistant should pair-program with the developer rather than building the entire application automatically.
